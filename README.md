# Weather App

A Python application that fetches live weather data using the Open-Meteo API.

## Features

- Search weather by city name
- Automatically finds city coordinates
- Displays current temperature
- Displays wind speed
- Displays weather condition
- Displays observation time
- Handles invalid city names
- Uses real-time weather data from an API

## Example

Input:

Enter city name: Hyderabad 

Output:

🌤️ Weather Report 
📍 City: Hyderabad 
🌡️ Temperature: 31.2 °C 
💨 Wind Speed: 5.1 km/h 
🌫️ Weather Condition: Partly Cloudy 
🕒 Time: 2026-06-01 18:45
